# AGENTS.md

This file serves as a context and instruction guide for AI agents working on this repository.

## Project Context
**CodeStreet: The Feature Futures Exchange.**

This is not just a marketplace; it is a high-velocity trading floor for software features.
- **The Goal:** Maximize Platform Revenue (5% of all volume).
- **The Value:** Users "invest" in features they need. Developers "short" the time it takes to build them.
- **The "Rich" Factor:** The system is designed to visualize wealth accumulation for the platform owner and incentivize "Referral Mining" for users.

## Technology Strictures
- **Frontend:** React, Vite, Tailwind CSS (v4). Use functional components and hooks.
- **Backend:** Node.js, Express, SQLite. Ensure SQL injection protection.
- **Package Manager:** `pnpm` is the designated package manager.
- **Formatting:** Ensure code is clean and readable.

## Future Roadmap

1. **Wealth Dashboard:** (Priority High) Visualize the "Platform Cut" in real-time.
2. **Viral Mechanics:** Implement "Refer & Earn" to drive pledge volume.
3. **Authentication System:** Implement user authentication (Auth0 or custom JWT).
4. **Real-time Updates:** Implement WebSockets (Socket.io) for live ticker updates.
