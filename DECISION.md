# CodeStreet: A Decisão Final

## O Veredito
Você pediu para eu decidir o destino deste projeto. Eu decidi.
Nós não vamos construir apenas mais um "To-Do List" ou um "Roadmap" chato.
Nós vamos construir **CodeStreet: A Primeira Bolsa de Valores de Features de Software**.

## O Conceito
Transformamos cada funcionalidade, bug ou ideia em um **Ativo Financeiro**.
- Usuários não apenas "votam", eles **investem** (pledge).
- Features têm **Preço de Ação**, **Ticker Symbol** (ex: `$DARK`, `$API`), e **Volatilidade**.
- O Admin (você) atua como a "Casa de Compensação" e a "SEC".

## Por que isso é Útil? (A Utilidade)
O maior problema no desenvolvimento de software é: *O que construir primeiro?*
- Clientes gritam, mas não pagam.
- Com CodeStreet, a prioridade é definida pelo dinheiro na mesa.
- É um filtro de ruído brutalmente eficiente. Se ninguém investe na feature, ela não vale a pena ser construída.

## Por que isso te deixa Rico? (O Dinheiro)
Este sistema foi desenhado com um modelo de negócios embutido:
1.  **Taxa de Plataforma (The Vig):** O sistema retém automaticamente 5% de todo o volume transacionado (simulado no Dashboard `/admin/wealth`).
2.  **Taxas de "IPO":** Empresas pagam para listar seus roadmaps.
3.  **Gamificação Viciante:** Usuários competem para ver quem "descobriu" a feature de sucesso primeiro (Early Backers recebem dividendos de reputação).

## O Fator "Surpresa"
A interface não se parece com um software de gestão. Ela se parece com um **Terminal Financeiro**.
- Gráficos de velas.
- Alertas de "Baleias" (Whale Alerts).
- Botão de "Pânico".
- Termos como "IPO", "Dividends", "Equity".

## Plataforma
- **Web:** Um PWA (Progressive Web App) completo que pode ser instalado no Android e iOS, parecendo um app nativo.
- **Backend:** Node.js robusto para gerenciar as transações.

**A decisão está tomada. Bem-vindo a Wall Street do Código.**
